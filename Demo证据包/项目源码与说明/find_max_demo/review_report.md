## 缺陷 1（严重）：全负数列表错误返回 0

**位置**：`max_val = 0` 初始化

**问题**：函数把最大值初值写死成 0。当输入全是负数的列表时，循环里没有任何一个元素 `>` 0，于是 `max_val` 永远停在初始的 0，返回错误结果。

**复现**：
```python
find_max([-1, -2, -3])   # 实际返回 0，正确应为 -1
find_max([-5, -3, -8])   # 实际返回 0，正确应为 -3
```

**影响**：业务逻辑错误，静默给出错误答案，调用方无法察觉。

**修复建议**：极值初值应从列表首元素取，即 `max_val = nums[0]`（需先处理空列表，见缺陷 2）。

---

## 缺陷 2（严重）：空列表静默返回 0

**位置**：函数未对空列表做处理

**问题**：当 `nums` 为空 `[]` 时，`for` 循环一次都不执行，直接返回初始值 0。函数既不报错也不给任何提示，返回一个在业务上毫无意义的 0。

**复现**：
```python
find_max([])   # 实际返回 0，应明确报错而非静默返回
```

**影响**：静默失败（silent failure）。上游若拿 0 当真实最大值继续计算，会污染整条数据链路且难以定位。

**修复建议**：在函数开头显式判断空列表，抛出 `ValueError("nums 不能为空")`，让错误尽早暴露。
